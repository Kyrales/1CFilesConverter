# Конвертация обработок 1С

Проект содержит скрипты для конвертации обработок 1С из формата EDT в бинарный EPF формат.

## Структура проекта

```
projects/
├── base.env                              # Общие настройки платформы
├── convert.py                            # Python скрипт конвертации
├── convert_v2.cmd                        # CMD обертка (универсальная)
├── convert_ОбдНСИ.cmd                    # CMD обертка (для конкретного проекта)
└── ЦПС_ОбработкаСправочниковОбдНСИ/      # Папка проекта
    ├── dp2epf.cmd                        # Скрипт конвертации из 1CFilesConverter
    └── ОбдНСИ.env                        # Настройки проекта
```

## Файлы проекта

- **`base.env`** - общие настройки платформы 1С и инструментов (версии, пути к EDT, ring и т.д.)
- **`convert.py`** - Python скрипт конвертации с поддержкой объединения .env файлов
- **`convert_v2.cmd`** - универсальная CMD обертка, принимает путь к папке проекта
- **`convert_ОбдНСИ.cmd`** - CMD обертка с жестко заданным путем к проекту ОбдНСИ
- **`ЦПС_ОбработкаСправочниковОбдНСИ/`** - папка проекта с настройками и скриптом конвертации

## Параметры

### convert_v2.cmd

- **Позиционный параметр** - путь к папке проекта (обязательный)
  - Может быть абсолютным или относительным
  - Папка должна содержать .env файлы и скрипт конвертации (dp2epf.cmd)

### convert.py

- **`--env`** (или `-e`) - путь к папке проекта
  - Если не указан, ищет .env файлы в папке со скриптом
  - Автоматически объединяет base.env (из папки скрипта) + .env файлы из папки проекта
- **`--output`** (или `-o`) - путь для сохранения EPF файла (переопределяет V8_DST_PATH из .env)

## Объединение .env файлов

Скрипт автоматически объединяет настройки из двух источников:

### Порядок объединения

1. **base.env** - из папки со скриптом convert.py (общие настройки платформы)
2. **Все .env файлы** - из папки проекта (специфичные настройки проекта)

При объединении последующие файлы переопределяют значения из предыдущих.

### Разделение настроек

**base.env** (в папке projects/) - общие параметры:
- Версии платформы 1С и EDT
- Пути к инструментам (1cv8.exe, 1cedtcli.exe, ring.cmd)
- Настройки кодировки и временных файлов
- Редко меняются

**проект.env** (в папке проекта) - специфичные настройки:
- ScriptName - имя скрипта конвертации
- V8_SRC_PATH - путь к исходникам
- V8_DST_PATH - путь для сохранения результата
- Часто меняются

### Пример структуры

```
projects/
├── base.env                              # Общие настройки
├── convert.py
├── convert_v2.cmd
└── ЦПС_ОбработкаСправочниковОбдНСИ/      # Папка проекта
    ├── dp2epf.cmd                        # Скрипт конвертации
    └── ОбдНСИ.env                        # Настройки проекта
```

## Настройки в .env

### base.env - общие настройки платформы

```env
# Версия платформы 1С
V8_VERSION=8.3.27.1989

# Версия EDT
V8_EDT_VERSION=2025.1.5

# Путь к 1cv8.exe (с кавычками для путей с пробелами)
V8_TOOL="C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe"

# Путь к EDT CLI
EDTCLI_TOOL="f:\1C\Projects\EDT\installations\1C_EDT 2025.1\1cedt\1cedtcli.exe"

# Путь к ring
RING_TOOL="c:\Program Files\1C\1CE\components\1c-enterprise-ring-0.11.10+2-x86_64\ring.cmd"

# Каталог для временных файлов
V8_TEMP=f:\1C\Projects\1CFilesConverter\temp

# Кодировка вывода (1251 для Windows)
V8_ENCODING=1251

# Очистка каталога назначения перед конвертацией (1 - да, 0 - нет)
V8_DP_CLEAN_DST=1
```

### проект.env - настройки конкретного проекта

```env
# Имя скрипта конвертации (обязательно)
ScriptName=dp2epf.cmd

# Путь к исходной обработке в формате EDT (обязательно)
V8_SRC_PATH=f:\1C\Projects\uh-mrg_obd_nsi\src\epf\ЦПС_ОбработкаСправочниковОбдНСИ

# Путь для сохранения EPF файла (обязательно)
V8_DST_PATH=f:\1C\Projects\uh-mrg_obd_nsi\src\epf\ЦПС_ОбработкаСправочниковОбдНСИ\bin
```

### Специальные переменные

- **ScriptName** - имя скрипта конвертации (обязательно в проект.env)
  - Может быть: dp2epf.cmd, conf2xml.cmd, conf2edt.cmd и т.д.
  - Скрипт должен находиться в той же папке, что и .env файл проекта

## Особенности

1. **Автоматическое объединение base.env**: При указании папки проекта через --env, скрипт автоматически:
   - Сначала загружает base.env из папки со скриптом convert.py
   - Затем загружает все .env файлы из папки проекта
   - Объединяет их (настройки проекта переопределяют base.env)

2. **Гибкая структура проектов**: Каждый проект может иметь свою папку с:
   - Одним или несколькими .env файлами с настройками
   - Скриптом конвертации (dp2epf.cmd и т.д.)

3. **Временный объединенный .env**: При объединении нескольких .env файлов создается временный файл, который автоматически удаляется после конвертации.

4. **Кодировка**: Скрипт автоматически обрабатывает кириллицу в путях благодаря использованию кодировки cp1251.

5. **Относительные пути**: Все относительные пути преобразуются в абсолютные относительно текущего рабочего каталога.

6. **Кавычки в путях**: Пути с пробелами автоматически заключаются в кавычки при создании временного .env файла.

7. **Цветной вывод**: Сообщения выводятся с цветовой подсветкой:
   - Зеленый - [INFO] и [SUCCESS]
   - Красный - [ERROR]
   - Желтый - [WARNING]

8. **Два варианта CMD оберток**:
   - `convert_v2.cmd` - универсальная, принимает путь как параметр
   - `convert_ОбдНСИ.cmd` - с жестко заданным путем для удобства

## Устранение проблем

### Ошибка "Python не найден"

Убедитесь, что Python установлен и добавлен в PATH:
```cmd
where python
```

### Ошибка "Не указан путь к папке проекта"

При использовании convert_v2.cmd обязательно передайте путь к папке проекта:
```cmd
convert_v2.cmd "ЦПС_ОбработкаСправочниковОбдНСИ"
```

### Ошибка "Папка не существует"

Проверьте правильность пути к папке проекта. Путь может быть:
- Относительным: `ЦПС_ОбработкаСправочниковОбдНСИ`
- Абсолютным: `F:\1C\Projects\1CFilesConverter\projects\ЦПС_ОбработкаСправочниковОбдНСИ`

### Ошибка "Could not find 1C:Designer"

Проверьте правильность пути V8_TOOL в base.env и наличие кавычек для путей с пробелами.

### Ошибка "Переменная ScriptName не определена"

Убедитесь, что в .env файле проекта указана переменная ScriptName:
```env
ScriptName=dp2epf.cmd
```

### Ошибка "Скрипт dp2epf.cmd не найден"

Скрипт конвертации должен находиться в той же папке, что и .env файл проекта:
```
ЦПС_ОбработкаСправочниковОбдНСИ/
├── dp2epf.cmd          # Скрипт конвертации
└── ОбдНСИ.env          # Настройки проекта
```

### Ошибка кодировки в путях

Убедитесь, что V8_ENCODING=1251 в base.env.

### Не найдены .env файлы

Если скрипт не находит .env файлы в папке проекта:
1. Проверьте, что файлы имеют расширение `.env`
2. Убедитесь, что вы указали правильный путь к папке проекта
3. Проверьте, что base.env существует в папке projects/
