# План создания GUI для конвертера 1С файлов

## Общая информация

**Цель**: Создать графический интерфейс на PySimpleGUI в стиле Cyberpunk для управления конвертацией файлов 1С через `convert.py`

**Расположение**: `f:\1C\Projects\1CFilesConverter\projects\converter_gui.py`

**Стиль**: Cyberpunk (неоново-синий, темный фон)

---

## Этап 1: Анализ и подготовка данных

### 1.1 Сканирование проектов
- Сканировать папку `f:\1C\Projects\1CFilesConverter\projects\`
- Найти все подпапки, содержащие `.env` файлы
- Для каждой подпапки:
  - Извлечь имя папки (Наименование)
  - Прочитать `.env` и извлечь:
    - `ScriptName` - имя CMD скрипта (Скрипт)
    - `V8_DST_PATH` - путь выгрузки (Путь выгрузки)
  - **Примечание**: CMD скрипты берутся из `projects/scripts/`, а не из папки проекта

### 1.2 Структура данных проекта
```python
{
    'name': 'ЦПС_ОбработкаСправочниковОбдНСИ',
    'script': 'dp2epf.cmd',  # из ScriptName в .env
    'project_path': 'f:\\...\\ЦПС_ОбработкаСправочниковОбдНСИ',  # путь к папке проекта
    'env_path': 'f:\\...\\ОбдНСИ.env',
    'dst_path': 'f:\\Output\\',  # из V8_DST_PATH или пустая строка
    'custom_dst_path': None,  # пользовательский путь (если изменен)
    'selected': False  # чекбокс
}
```

**Важно**: Скрипты конвертации находятся в `projects/scripts/`, а не в папке проекта

## Этап 3: Логика работы

### 3.1 Инициализация
1. Запуск GUI
2. Сканирование папки `projects/`
3. Загрузка данных проектов
4. Отображение в таблице

**Примечание**: Кнопка "Обновить проекты (F5)" выполняет те же шаги 2-4

### 3.2 Взаимодействие с таблицей
- Клик по чекбоксу - переключение выбора проекта
- Клик по кнопке `[...]` - открытие диалога выбора пути:
  - Определить тип скрипта (по ScriptName из .env)
  - Если `.cf` или `.cfe` - диалог выбора файла
  - Если `.epf` или `.erf` - диалог выбора папки
  - Сохранить в `custom_dst_path`
  - Обновить отображение в таблице

### 3.2.1 Изменение порядка строк
- Кнопка `Вверх ▲`:
  - Получить индекс выбранной строки в таблице
  - Если индекс > 0, поменять местами с предыдущей строкой
  - Обновить таблицу
  - Сохранить выделение на перемещенной строке
- Кнопка `Вниз ▼`:
  - Получить индекс выбранной строки в таблице
  - Если индекс < (количество строк - 1), поменять местами со следующей строкой
  - Обновить таблицу
  - Сохранить выделение на перемещенной строке
- Порядок строк определяет порядок выполнения конвертации

### 3.3 Выполнение конвертации
При нажатии кнопки `Выполнить`:

1. Проверить, что выбран хотя бы один проект
2. Получить список выбранных проектов
3. Инициализировать прогресс-бар (0 из N)
4. Переключиться на вкладку "Лог выполнения"
5. Для каждого выбранного проекта (в порядке отображения в таблице):
   - Обновить статус: "Конвертация: {название проекта}..."
   - Сформировать команду:
     ```python
     # project_path - путь к папке проекта (где находится .env)
     cmd = ['python', 'convert.py', '--env', project_path]
     if custom_dst_path:
         cmd.extend(['--output', custom_dst_path])
     ```
   - **Примечание**: `convert.py` автоматически:
     - Загружает `base.env` (если есть)
     - Загружает `.env` из папки проекта
     - Берет CMD скрипт из `projects/scripts/` по имени из `ScriptName`
   - Запустить subprocess с перехватом stdout/stderr
   - Читать вывод построчно и добавлять в лог
   - Вычислить процент: `(completed / total) * 100`
   - Обновить прогресс-бар: "Выполнено: X из N (Y%)"
   - При ошибке - продолжить со следующим проектом
6. По завершении всех проектов:
   - Статус: "Готово! Выполнено: N из N (100%)"
   - Показать итоговое сообщение

### 3.4 Перехват вывода convert.py
- Использовать `subprocess.Popen` с `stdout=PIPE, stderr=PIPE`
- Читать построчно в реальном времени
- Парсить цветовые коды ANSI и преобразовывать в текстовые метки
- Обновлять GUI через `window.write_event_value()`

## Этап 4: Cyberpunk стилизация

### 4.1 Цветовая схема
```python
COLORS = {
    'bg': '#0f0f1e',           # Темный фон
    'bg_secondary': '#1a1a2e', # Вторичный фон
    'primary': '#00d9ff',      # Неоново-синий (основной)
    'accent': '#ff006e',       # Неоново-розовый (акцент)
    'success': '#00ff88',      # Успех
    'error': '#ff0055',        # Ошибка
    'warning': '#ffdd00',      # Предупреждение
    'text': '#e0e0e0',         # Основной текст
    'text_dim': '#808080'      # Приглушенный текст
}
```

### 4.2 Настройка темы PySimpleGUI
```python
sg.theme_add_new('Cyberpunk', {
    'BACKGROUND': COLORS['bg'],
    'TEXT': COLORS['text'],
    'INPUT': COLORS['bg_secondary'],
    'TEXT_INPUT': COLORS['primary'],
    'SCROLL': COLORS['bg_secondary'],
    'BUTTON': (COLORS['bg'], COLORS['primary']),
    'PROGRESS': (COLORS['primary'], COLORS['bg_secondary']),
    'BORDER': 1,
    'SLIDER_DEPTH': 0,
    'PROGRESS_DEPTH': 0
})
sg.theme('Cyberpunk')
```

## Этап 5: Обработка ошибок

### 5.1 Проверки при запуске
- Существование папки `projects/`
- Наличие `convert.py`
- Наличие Python в PATH
- Права на чтение .env файлов

### 5.2 Обработка ошибок выполнения
- Проект не найден
- Ошибка чтения .env
- Ошибка запуска convert.py
- Прерывание пользователем (кнопка "Отмена")

### 5.3 Логирование ошибок
- Все ошибки выводить в лог с меткой `[ERROR]`
- Не прерывать выполнение остальных проектов при ошибке в одном

### 6.1 Кнопка "Обновить проекты (F5)"
- Пересканировать папку `projects/`

- Обновить таблицу
- Сбросить текущие выборы и пользовательские пути (полная переинициализация)
- Горячая клавиша: F5

### 6.2 Сохранение состояния (опционально)
- Сохранять выбранные проекты в конфиг
- Сохранять пользовательские пути выгрузки
- Восстанавливать при следующем запуске

### 6.3 Сохранение лога
- Кнопка `Сохранить лог`:
  - Открыть диалог `sg.popup_get_file()` с фильтром `*.log`
  - По умолчанию предложить имя: `converter_log_YYYYMMDD_HHMMSS.log`
  - Сохранить содержимое лога в выбранный файл
  - Показать сообщение об успешном сохранении

### 6.4 Горячие клавиши

- `Ctrl+D` - Снять все
- `F5` - Обновить проекты
- `Ctrl+S` - Сохранить лог
- `Enter` - Выполнить (если фокус на кнопке)

## Примечания

- GUI не закрывается после выполнения - можно запускать повторно
- Пользовательские пути выгрузки сохраняются только на время сессии
- `base.env` обрабатывается автоматически внутри `convert.py`
- CMD скрипты берутся из `projects/scripts/`, а не из папки проекта
- Валидация путей по типу скрипта (файл/папка) выполняется в `convert.py`
- Последовательное выполнение проектов (не параллельное)
- Порядок выполнения определяется порядком строк в таблице GUI
