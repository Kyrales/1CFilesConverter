# Быстрый старт GUI конвертера

## Запуск

Двойной клик по файлу: **`run_gui.cmd`**

## Основные действия

### 1. Выбор проектов
- Кликните по строке проекта → появится ✓
- Или используйте кнопку `Выбрать все`

### 2. Изменение порядка (опционально)
- Выберите проект
- Нажмите `Вверх ▲` или `Вниз ▼`

### 3. Изменение пути выгрузки (опционально)
- Выберите проект
- Нажмите `Изменить путь...`
- Выберите файл или папку

### 4. Запуск конвертации
- Нажмите `ВЫПОЛНИТЬ`
- Наблюдайте за прогрессом на вкладке "Лог выполнения"

### 5. Сохранение лога (опционально)
- Перейдите на вкладку "Лог выполнения"
- Нажмите `Сохранить лог`

## Горячие клавиши

- **F5** - Обновить список проектов
- **Ctrl+A** - Выбрать все
- **Ctrl+D** - Снять все

## Важно

✅ GUI не закрывается после выполнения - можно запускать повторно

✅ Проекты выполняются последовательно

✅ При ошибке в одном проекте выполнение продолжается
