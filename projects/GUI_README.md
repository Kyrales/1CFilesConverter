# GUI для конвертера 1С файлов

## Описание

Графический интерфейс в стиле Cyberpunk для управления конвертацией файлов 1С через `convert.py`.

## Установка зависимостей

```bash
pip install FreeSimpleGUI
```

Или если у вас есть лицензия PySimpleGUI:
```bash
pip install --upgrade --extra-index-url https://PySimpleGUI.net/install PySimpleGUI
```

## Запуск

### Windows
Двойной клик по файлу:
```
run_gui.cmd
```

Или через командную строку:
```bash
python converter_gui.py
```

## Возможности

### Вкладка "Проекты"

- **Таблица проектов** с колонками:
  - `✓` - Чекбокс для выбора проекта
  - `Наименование` - имя папки проекта
  - `Скрипт` - имя .cmd файла конвертации
  - `Путь выгрузки` - путь назначения из .env или пользовательский

- **Кнопки управления**:
  - `Выбрать все` - выбрать все проекты
  - `Снять все` - снять выбор со всех проектов
  - `Вверх ▲` - переместить выбранный проект вверх (изменить порядок выполнения)
  - `Вниз ▼` - переместить выбранный проект вниз
  - `Изменить путь...` - изменить путь выгрузки для выбранного проекта
  - `Обновить проекты (F5)` - пересканировать папку projects
  - `ВЫПОЛНИТЬ` - запустить конвертацию выбранных проектов

- **Прогресс-бар**:
  - Показывает общий прогресс выполнения
  - Отображает процент выполнения
  - Текущий статус конвертации

### Вкладка "Лог выполнения"

- **Область лога**:
  - Вывод в реальном времени
  - Цветовое кодирование сообщений:
    - `[INFO]` - информационные сообщения
    - `[ERROR]` - ошибки
    - `[WARNING]` - предупреждения
    - `[SUCCESS]` - успешное завершение
  - Автоскролл к последней строке

- **Кнопки**:
  - `Очистить лог` - очистить содержимое лога
  - `Сохранить лог` - сохранить лог в файл .log

## Горячие клавиши

- `Ctrl+A` - Выбрать все проекты
- `Ctrl+D` - Снять все выборы
- `F5` - Обновить список проектов
- `Ctrl+S` - Сохранить лог

## Использование

1. Запустите GUI
2. В таблице отобразятся все проекты из папки `projects/` с .env файлами
3. Кликните по строке проекта чтобы выбрать/снять выбор (появится ✓)
4. При необходимости измените порядок выполнения кнопками `Вверх ▲` / `Вниз ▼`
5. Если нужно изменить путь выгрузки:
   - Выберите проект в таблице
   - Нажмите `Изменить путь...`
   - Выберите файл (для .cf/.cfe) или папку (для .epf/.erf)
6. Нажмите `ВЫПОЛНИТЬ`
7. Автоматически переключится на вкладку "Лог выполнения"
8. Наблюдайте за прогрессом выполнения
9. После завершения можно запустить конвертацию повторно

## Структура проекта

```
projects/
├── converter_gui.py          # Главный файл GUI
├── run_gui.cmd              # Скрипт запуска для Windows
├── convert.py               # Скрипт конвертации
├── base.env                 # Базовые настройки
└── [папки проектов]/
    ├── *.env                # Настройки проекта
    └── *.cmd                # Скрипт конвертации
```

## Цветовая схема Cyberpunk

- Темный фон: `#0f0f1e`
- Неоново-синий: `#00d9ff` (основной цвет)
- Неоново-розовый: `#ff006e` (акцент)
- Успех: `#00ff88`
- Ошибка: `#ff0055`
- Предупреждение: `#ffdd00`

## Примечания

- GUI не закрывается после выполнения - можно запускать конвертацию повторно
- Пользовательские пути выгрузки сохраняются только на время сессии
- Проекты выполняются последовательно в порядке отображения в таблице
- При ошибке в одном проекте выполнение продолжается со следующего
