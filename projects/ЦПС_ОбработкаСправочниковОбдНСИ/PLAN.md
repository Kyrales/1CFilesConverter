# План конвертации обработки ЦПС_ОбработкаСправочниковОбдНСИ из EDT в EPF

## Цель
Конвертировать обработку из формата EDT в бинарный EPF-файл

## Исходные данные
- **Источник**: `f:\1C\Projects\uh-mrg_obd_nsi\src\epf\ЦПС_ОбработкаСправочниковОбдНСИ\` (формат EDT)
- **Назначение**: `f:\1C\Projects\1CFilesConverter\build\ЦПС_ОбработкаСправочниковОбдНСИ.epf`
- **Скрипт конвертации**: `f:\1C\Projects\1CFilesConverter\scripts\dp2epf.cmd`

## Параметры среды
- **V8_VERSION**: 8.3.27.1989
- **V8_EDT_VERSION**: 2025.1.5
- **V8_TOOL**: `C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe`
- **V8_TEMP**: `f:\1C\Projects\1CFilesConverter\temp`
- **V8_ENCODING**: 65001 (UTF-8)
- **V8_BASE_CONFIG**: не указывается (будет использована пустая конфигурация)
- **V8_BASE_IB**: не указывается (будет создана временная информационная база)
- **V8_DP_CLEAN_DST**: 1 (очистка каталога назначения перед конвертацией)

## Файлы для создания

### 1. Файл `.env`
**Путь**: `projects/ЦПС_ОбработкаСправочниковОбдНСИ/.env`

Содержит переменные среды для конвертации:
```env
V8_VERSION=8.3.27.1989
V8_EDT_VERSION=2025.1.5
V8_TOOL=C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe
V8_TEMP=f:\1C\Projects\1CFilesConverter\temp
V8_ENCODING=65001
V8_DP_CLEAN_DST=1
```

### 2. Скрипт конвертации `convert.cmd`
**Путь**: `projects/ЦПС_ОбработкаСправочниковОбдНСИ/convert.cmd`

Выполняет конвертацию обработки из EDT в EPF:
```cmd
@ECHO OFF
SETLOCAL

REM Установка путей
set PROJECT_DIR=%~dp0
set SCRIPTS_DIR=f:\1C\Projects\1CFilesConverter\scripts
set SRC_PATH=f:\1C\Projects\uh-mrg_obd_nsi\src\epf\ЦПС_ОбработкаСправочниковОбдНСИ
set DST_PATH=%PROJECT_DIR%build

REM Создание каталога build если не существует
if not exist "%DST_PATH%" mkdir "%DST_PATH%"

REM Вызов скрипта конвертации dp2epf.cmd
call "%SCRIPTS_DIR%\dp2epf.cmd" "%SRC_PATH%" "%DST_PATH%"

if ERRORLEVEL 1 (
    echo [ERROR] Ошибка конвертации обработки
    exit /b 1
)

echo [SUCCESS] Обработка успешно сконвертирована: %DST_PATH%\ЦПС_ОбработкаСправочниковОбдНСИ.epf

ENDLOCAL
```

2. Создать скрипт `convert.cmd`
3. Создать каталог `build` (создается автоматически скриптом)
4. Запустить `convert.cmd` из каталога `projects/ЦПС_ОбработкаСправочниковОбдНСИ/`

## Команда запуска

```cmd
cd /d f:\1C\Projects\1CFilesConverter\projects\ЦПС_ОбработкаСправочниковОбдНСИ

```

## Примечания

1. Скрипт `dp2epf.cmd` автоматически:
   - Прочитает переменные из `.env`
   - Создаст временную информационную базу в `%V8_TEMP%`
   - Загрузит пустую конфигурацию
   - Сконвертирует EDT-проект в EPF
   - Очистит временные файлы

2. Если каталог `build` содержит старый EPF-файл, он будет заменен (благодаря `V8_DP_CLEAN_DST=1`)

3. Путь к утилитам EDT (ring, 1cedtcli) будет определен автоматически на основе `V8_EDT_VERSION`

4. Лог выполнения будет выведен в консоль с кодировкой UTF-8

## Возможные проблемы и решения

- **Ошибка "Не найден 1cv8.exe"**: Проверить правильность версии в `V8_VERSION`
- **Ошибка "Не найден ring/1cedtcli"**: Проверить установку EDT версии 2025.1.5
- **Ошибка доступа к файлам**: Проверить права доступа к каталогам
- **Ошибка создания временной базы**: Проверить наличие каталога `f:\1C\Projects\1CFilesConverter\temp`
