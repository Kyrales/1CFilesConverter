# Конвертация обработки ЦПС_ОбработкаСправочниковОбдНСИ

Проект содержит скрипты для конвертации обработки 1С из формата EDT в бинарный EPF формат.

## Файлы проекта

- **`.env`** - файл с переменными окружения (настройки конвертации)
- **`convert.py`** - Python скрипт конвертации
- **`convert_v2.cmd`** - CMD обертка для запуска Python скрипта
- **`convert.cmd`** - оригинальный CMD скрипт (устаревший)
- **`dp2epf.cmd`** - базовый скрипт конвертации из 1CFilesConverter

## Использование

### Вариант 1: Через CMD обертку (рекомендуется)

```cmd
REM Автоматический поиск всех .env файлов в папке скрипта
convert_v2.cmd

REM Указание каталога с .env файлами (текущий каталог)
convert_v2.cmd --env .

REM Указание каталога с .env файлами (относительный путь)
convert_v2.cmd --env ../configs

REM Указание конкретных .env файлов
convert_v2.cmd --env base.env --env ЦПС_ОбработкаСправочниковОбдНСИ.env

REM С указанием другого пути назначения
convert_v2.cmd --output f:\1C\Projects\build

REM Комбинация: каталог с .env + переопределение пути
convert_v2.cmd --env . --output ..\build
```

### Вариант 2: Напрямую через Python

```cmd
REM Автоматический поиск всех .env файлов в папке скрипта
python convert.py

REM Указание каталога с .env файлами
python convert.py --env .
python convert.py --env ../configs

REM Указание конкретного .env файла
python convert.py --env base.env

REM Объединение нескольких .env файлов
python convert.py --env base.env --env ЦПС_ОбработкаСправочниковОбдНСИ.env

REM Смешанный режим: каталог + файл
python convert.py --env ../common --env local.env

REM С указанием другого пути назначения
python convert.py --env . --output f:\1C\Projects\build

REM Справка по параметрам
python convert.py --help
```

## Параметры

### Обязательные параметры

Нет обязательных параметров. Если не указан `--env`, автоматически используются все `.env` файлы из папки скрипта.

### Опциональные параметры

- **`--env`** (или `-e`) - путь к .env файлу или каталогу с .env файлами
  - Можно указать несколько раз для объединения
  - Поддерживает абсолютные и относительные пути
  - Если указан каталог, будут найдены все `*.env` файлы в нем
  - Если указан файл, будет использован только этот файл
- **`--output`** (или `-o`) - путь для сохранения EPF файла (переопределяет V8_DST_PATH из .env)

## Объединение .env файлов

Скрипт поддерживает гибкое объединение .env файлов из разных источников:

### Способы указания .env файлов

1. **Автоматический поиск** - без параметров ищет все `*.env` в папке скрипта
2. **Каталог** - `--env .` или `--env ../configs` - найдет все `*.env` в указанном каталоге
3. **Конкретный файл** - `--env base.env` - использует только указанный файл
4. **Комбинация** - можно комбинировать каталоги и файлы

### Порядок объединения

При объединении последующие файлы переопределяют значения из предыдущих:
- Файлы из каталогов обрабатываются в алфавитном порядке
- При указании нескольких `--env` они обрабатываются слева направо

### Разделение настроек

Рекомендуется разделять настройки на:
- **base.env** - общие параметры платформы, пути к инструментам (редко меняются)
- **проект.env** - специфичные настройки проекта (часто меняются)

### Примеры объединения

```cmd
REM Все .env из текущего каталога (base.env + ЦПС_ОбработкаСправочниковОбдНСИ.env)
convert_v2.cmd --env .

REM Общие настройки из другого каталога + локальные настройки
convert_v2.cmd --env ../common --env local.env

REM Явное указание порядка объединения
convert_v2.cmd --env base.env --env ЦПС_ОбработкаСправочниковОбдНСИ.env
```

### Пример структуры файлов

**base.env** - общие настройки:

V8_TEMP=f:\1C\Projects\1CFilesConverter\temp
V8_ENCODING=1251

**ЦПС_ОбработкаСправочниковОбдНСИ.env** - настройки проекта:
```env

V8_DST_PATH=f:\1C\Projects\1CFilesConverter\build
```

## Настройки в .env

### Специальные переменные

- **ScriptName** - имя скрипта конвертации (по умолчанию: dp2epf.cmd)
  - Может быть: dp2epf.cmd, conf2xml.cmd, conf2edt.cmd и т.д.

### Общие переменные

```env
# Версия платформы 1С
V8_VERSION=8.3.27.1989

# Версия EDT
V8_EDT_VERSION=2025.1.5

# Путь к 1cv8.exe (с кавычками для путей с пробелами)
V8_TOOL="C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe"

# Путь к EDT CLI (опционально)
EDTCLI_TOOL="f:\1C\Projects\EDT\installations\1C_EDT 2025.1\1cedt\1cedtcli.exe"

# Путь к ring (опционально)
RING_TOOL="c:\Program Files\1C\1CE\components\1c-enterprise-ring-0.11.10+2-x86_64\ring.cmd"

# Каталог для временных файлов
V8_TEMP=f:\1C\Projects\1CFilesConverter\temp

# Кодировка вывода (1251 для Windows)
V8_ENCODING=1251

# Очистка каталога назначения перед конвертацией (1 - да, 0 - нет)
V8_DP_CLEAN_DST=1

# Путь к исходной обработке в формате EDT
V8_SRC_PATH=f:\1C\Projects\uh-mrg_obd_nsi\src\epf\ЦПС_ОбработкаСправочниковОбдНСИ

# Путь для сохранения EPF файла
V8_DST_PATH=f:\1C\Projects\1CFilesConverter\build
```

## Особенности

1. **Автоматический поиск .env**: Если параметр `--env` не указан, скрипт автоматически находит все `*.env` файлы в папке скрипта и объединяет их в алфавитном порядке.

2. **Гибкое указание источников**: Параметр `--env` может принимать:
   - Путь к файлу: `--env base.env`
   - Путь к каталогу: `--env .` или `--env ../configs`
   - Можно комбинировать: `--env ../common --env local.env`

3. **Временный объединенный .env**: При наличии нескольких .env файлов создается временный объединенный файл, который автоматически удаляется после конвертации.

4. **Кодировка**: Скрипт автоматически обрабатывает кириллицу в путях благодаря использованию кодировки cp1251.

5. **Относительные пути**: Все относительные пути преобразуются в абсолютные относительно текущего рабочего каталога.

6. **Кавычки в путях**: Пути с пробелами автоматически заключаются в кавычки при создании временного .env файла.

7. **Цветной вывод**: Сообщения выводятся с цветовой подсветкой:
   - Зеленый - [INFO] и [SUCCESS]
   - Красный - [ERROR]
   - Желтый - [WARNING]

## Устранение проблем

### Ошибка "Python не найден"

Убедитесь, что Python установлен и добавлен в PATH:
```cmd
where python
```

### Ошибка "Could not find 1C:Designer"

Проверьте правильность пути V8_TOOL в .env файле и наличие кавычек для путей с пробелами.

### Ошибка кодировки в путях

Убедитесь, что V8_ENCODING=1251 в .env файле.

### Не найдены .env файлы

Если скрипт не находит .env файлы:
1. Проверьте, что файлы имеют расширение `.env`
2. Убедитесь, что вы запускаете скрипт из правильного каталога
3. Попробуйте явно указать путь: `convert_v2.cmd --env .`

### Конфликт настроек при объединении

Если при объединении .env файлов возникают конфликты:
1. Помните, что последующие файлы переопределяют предыдущие
2. Используйте явное указание порядка: `--env base.env --env override.env`
3. Проверьте содержимое объединенных файлов в выводе скрипта
